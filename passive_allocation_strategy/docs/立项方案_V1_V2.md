# 被动配置策略 · 立项方案（V1 + V2）

> 日期：2026-09-19
> 定位：适合普通散户的"稳健配置型"策略，非交易型、非预测型。

## 总体思路

不预测涨跌，用**股债黄金的固定比例 + 定期再平衡**控制风险，靠"机械高抛低吸"和"长期复利"取胜。核心原则：**少做决策、少看盘、用时间换收益、用结构控风险。**

分两阶段：
- **V1（核心仓）**：资产配置 + 再平衡——压舱石，稳健兜底
- **V2（卫星仓，规划中）**：定投 + 估值调整——新钱投入机制，见下文

> 2026-09-19 池结构修订：降低 A 股集中度（沪深300 15→10、创业板 10→5）、纳指 15% 相对 A 股更高、新增标普500 10%。

### 再平衡机制（二选一触发，任一满足即调仓）

1. **定期**：每季度第一个交易日
2. **阈值**：任一资产实际权重偏离目标 > 5%（绝对）

### 执行

- 调仓到目标权重（聚宽用 `order_target_percent`）
- 佣金万三 + 最低 5 元

### 为什么这样设计

- 股债 6:4：股票提供成长，债券提供缓冲 + 再平衡"弹药"
- 红利 + 沪深300 + 创业板 + 纳指 + 标普500：A股价值/大盘/成长 + 美股双宽基，五个低相关来源
- 黄金 5%：股债双杀（滞胀）时的尾部保险
- 季度频率够低（不折腾），阈值触发能在剧烈波动时及时纠偏

**结论与决策：**
- 改池有效：同股 60%，新池 +57.70% vs 旧池 +55.49%，且回撤更低（11.45% vs 11.69%）、波动更低（9.47% vs 11.91%）、夏普更高（1.01 vs 0.80）——加标普500 + 降 A 股集中是帕累托改进。
- 股债比例是干净的风险收益曲线：股越多赚越多，回撤单调升（5.55%→17.18%），2018 熊市亏损单调恶化（+1.0%→-9.5%）。
- 股30/债65 是唯一 2018 不亏档位（+0.96%），股40/债55 基本打平（-0.8%）。
- **决策：暂时维持股60/债35**（不采用更保守的 40/55），A/B 结果留档备查。
- 提醒：2017-2021 是"股债双牛"，高债档位"无亏损年"有周期红利，选定后需聚宽 2022-2026 样本外复核。
- 数据瑕疵：本地复权因子对"份额拆分"处理有 bug（159928 消费 2021 拆分、纳指 2022-01、标普 2022-03 拆分），仅影响 2022 年后本地数据；当前 2017-2021 池内无影响。

## V2：定投 + 估值调整（卫星仓，规划中，尚未实现）

### 目标

解决"新钱怎么投入"的问题——普通散户每月有工资结余，需要一套机械的投入机制，避免"一次性买在顶部"。

### 设计（待细化）

- **定投**：固定时间（如每月发薪后第一个交易日）投入固定金额
- **估值调整**：按标的估值历史百分位调整单次投入金额
  - 低估（PE/PB 历史百分位 < 30%）→ 多买（如 1.5 倍）
  - 中性（30%~70%）→ 正常买
  - 高估（> 70%）→ 少买或不买（转入国债，等回落）

### 待确认

- 估值数据来源（聚宽 `get_fundamentals` / 本地估值数据）
- 估值百分位的计算窗口

## 风险提示（务必诚实）

- **没有"存款般稳定 + 5%"**：本策略长期期望 5-8%，但单年可能亏 5-10%
- "稳定"是"多年尺度上的均值"，不是"每年都正"
- 若需绝对稳定，只能接受无风险利率（定存/国债 ~2%）

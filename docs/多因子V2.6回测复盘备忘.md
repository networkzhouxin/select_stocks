## 四、能力圈：什么时候该信任它

三年对照复盘揭示了策略的"性格"——**它是"趋势/无趋势"的赌徒，不是"涨跌"的赌徒。只要市场有方向（向上或向下都行）就能跟上，只在"反复无方向"时失灵。**

### 高光样本：2022（全球股债双杀，它+7.1%）

四道防线协同：
1. **熊市检测全年开启**（242交易日全程触发）→ A股仓位全年减半，躲过4月封城重挫
2. **资产轮动涌入避险品**：买入最多的是豆粕(8)/黄金(7)/红利(6)
3. **盈利来源**：豆粕单品贡献+21.9%，是当年MVP（商品ETF平时鸡肋，通胀年变主力）
4. **几乎不空仓**（242天仅2天空仓）→ 靠"换到对的资产"防御，不是"躲进现金"

### 软肋样本：2024（脉冲震荡市，仅+4.9%）

- 全年净值在58k~64k横跳，6月见高后一路回吐
- **问题不是"门槛太高不敢动"，而是"动得太勤、每次换错"**：全年18次换仓，下半年12次
- 典型陷阱：10月用82分追高买中证1000（924脉冲）→ 11月跌到56.8分砍掉换标普 → 右侧追高被反向收割
- 病根：动量因子在脉冲市被假突破"骗"出高分，5天持仓+8分门槛"慢半拍"，买在脉冲顶、卖在回落底

### 2022 vs 2024 对照

| | 2022（高光） | 2024（软肋） |
|---|------------|------------|
| 市场特征 | 单边熊（趋势清晰） | 脉冲震荡（无趋势） |
| 避险资产 | 豆粕/黄金单边涨 → 吃到+21.9% | 黄金脉冲见顶 → 追高被套 |
| 换仓 | 换到对的资产并拿住 | 频繁换错、被反向收割 |
| 结果 | +7.1% | +4.9% |

## 五、实战心法

1. **市场有明确方向时（无论牛熊）→ 充分信任**（2022/2019/2025为证）
2. **脉冲震荡、热点快速轮动时 → 降低预期**（2017/2024为戒），大概率小赚或微亏，但极少大亏（14.4%回撤纪律仍在）
3. **永远不要在跑输大盘的年份（如2024）失去信心离场**——正是同一套"慢"逻辑，让它在2022灾难年保护了你。**踏空的代价和避坑的收益，是同一枚硬币的两面。**

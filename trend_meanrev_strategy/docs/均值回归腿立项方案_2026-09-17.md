## 1. 总体目标与分阶段

**最终形态**：一个策略文件内包含两条腿——趋势跟随（吃趋势行情）+ 均值回归（吃震荡行情），按品种特性路由，**不做市场状态择时切换**（V9 regime detection 历史翻车）。

**分阶段**：
1. 趋势腿：已单独开发（另一台电脑负责）
2. **均值回归腿**（本方案）：单独开发 → 回测 → 验证 → 稳定确认（本机负责）
3. 合成：两腿并入同一文件，并行资金分配（Phase 3 再定分配比例）

## 2. 品种池

整体 12 只（沿用 Multi-Factor V2.10 池），本腿取**天生均值回复**的 4 只：

| 代码 | 名称 | 均值回复的"锚" | 特性 |
|------|------|---------------|------|
| 518880.XSHG | 黄金 | 实际利率/避险锚 | V2.8 已实证均值回复型，趋势跟随的宽止损对它不适用 |
| 510880.XSHG | 红利 | 股息率锚 | V14 实证低波动均值回复，趋势跟随稀释 alpha |
| 159985.XSHE | 豆粕 | 供需锚 | 有均值回复，但带一定趋势性（V2.8 收紧止损翻车，需谨慎） |
| 511010.XSHG | 国债 | 票息锚 | 最典型均值回复；**当前数据根无此品种，待扩数据根后纳入** |

**为什么是这 4 只、为什么不扩到全池**：均值回归策略的前提是**资产必须有基本面锚**——黄金有实际利率锚、红利有股息率锚、豆粕有供需锚、国债有票息锚，偏离中枢后有回归动力。无锚资产（纳指/创业板等成长型）偏离可持续很久（趋势），不适合均值回归。这 4 只正是 AGENTS.md 历史教训里反复被标记为"不适合趋势跟随"的品种——它们留给本腿，趋势腿不用它们。

**明确不扩到 12 只全池**：全池反转（含无锚成长型）是 `resonance_reversal_strategy` 已独立承担的定位，本腿若照搬全池，既与趋势腿 9 只重叠、破坏"按品种路由"，又重复造轮子。resonance 值得借鉴的是**机制**，不是**池子**。

**国债 511010（已确认纳入，待扩数据根）**：票息锚、最典型均值回复。**当前数据根无 511010**，需用户授权扩展数据根（新增 511010 的 2016-2021 日线 + 09:35 分钟）后纳入；先跑通 3 只，国债数据到位再加。

**油气（已确认不纳入）**：V15.6/V15.7-Global 历史教训（油气止损率 37%+、拖累收益）、油价锚极不稳定（OPEC/地缘主导）、2020 负油价肥尾会打死均值回归。商品位由豆粕承担即可，不追求凑数。

## 3. 核心机制

- 单品种信号驱动均值回归（非横截面轮动）
- 学术默认参数，零参数优化（AGENTS.md 铁律）
- **布尔事件 + 共振真值表 + 无评分**（借鉴 resonance_reversal），不采用打分制

### 借鉴 resonance_reversal 的部分（机制精华，与品种无关）

1. **布尔事件 + 共振真值表 + 无评分**：比打分制严谨、可穷举测试、防过拟合
2. **BOLL(20,2) 触下轨回落 = 超卖结构确认**（必选）：当前或前一日触/破下轨 + `close > lower` + `close > 前收`
3. **RSI14 低位回升 / KDJ 低位拐头 = 动能确认**（至少一个）；**第三个指标反向则否决**
4. **事件新鲜度窗口**：2 个交易日，至少一个支持事件在 T-1
5. **ATR 只做风控**：不参与共振资格、候选排序、仓位计算
6. **工程细节**：防重复标识、`pending_exit` / `sold_today` 状态模型、确定性排序

### 不照搬 resonance_reversal 的部分（与均值回归定位冲突）

1. **品种池**：resonance 是 12 只全池；本腿保持 3 只有锚（见第 2 节）
2. **卖出**：resonance 是"触上轨回落"的顶部共振卖出（抓拐点）；均值回归是"回归中轨即了结"——回归目标就是中轨，等不到超买，必须更早了结（见第 4 节）
3. **接飞刀防护**：resonance 没有明确的趋势性下跌过滤（靠 ATR 兜底）；均值回归最怕接飞刀，必须补上
4. **时间止损**：resonance 没有；均值回归"错得快砍得快"，必须补上

### 其他参考来源

- **风控/执行/止损/盘后更新骨架**：复用趋势腿已建的 `local/` 工程骨架（`data_loader.py` 数据访问、ATR 止损、防未来函数边界、盘后更新最高价），不重复造轮子
- **不参考**：cross_signal 的横截面打分排序（本腿单品种独立判断）；趋势腿的"20 日新高突破"（方向相反）

## 4. 信号与规则（候选 v0，待确认）

**数据**：日线，`get_price()` 取 120 根日线截止 T-1；信号只用 T-1 及以前数据。

**指标默认参数**（学术默认，零优化）：RSI(14)、KDJ(9,3,3)、BOLL(20,2)、ATR(14)、MA(20,60)。

### 买入共振（布尔事件，T-1 收盘）

**结构确认（必选）— BOLL 超卖收回**：
- 当前或前一日的最低价/收盘价触及或低于布林下轨；
- 且 `close > lower`（已收回轨内）；
- 且 `close > 前收`（收盘方向确认）。

**动能确认（至少一个）**：
- **RSI 低位回升**：`RSI[i-1] <= 30` 且 `RSI[i] > RSI[i-1]`（不要求上穿 30）；
- 或 **KDJ 低位拐头**：前一日 `min(K,D) <= 20` 或 `J <= 0`，且最新 `J` 上升、`K-D` 差值大于前值（预交叉拐点，不等正式金叉）。

**否决条件（任一即不买）**：
- **第三指标反向**：未提供买入支持的那个指标出现高位回落拐点（RSI `>= 70` 且回落，或 KDJ `max(K,D) >= 80`/`J >= 100` 且回落）；
- **接飞刀防护**：**训练期 A/B 证伪后去掉**（见下"接飞刀防护"小节）；接飞刀风险由 ATR 止损 + 时间止损兜底；
- **防追高**：`RSI(14) > 75`（复用趋势腿 `is_overheated_for_buy`，均值回归中极少触发）。

**买入共振真值表**：

| BOLL 结构 | RSI | KDJ | 动作 |
|---|---|---|---|
| 超卖收回 | 低位回升 | 中性 | 买入候选 |
| 超卖收回 | 中性 | 低位拐头 | 买入候选 |
| 超卖收回 | 低位回升 | 低位拐头 | 买入候选（更强） |
| 超卖收回 | 低位回升 | 高位回落 | 冲突，不买 |
| 超卖收回 | 高位回落 | 低位拐头 | 冲突，不买 |
| 非超卖 | 任意 | 任意 | 不买 |

**事件新鲜度**：支持事件只取 T-1 或 T-2，至少一个在 T-1；两个旧事件不触发交易。

**买入选择**：合格数 > 3 时，先按"BOLL+RSI+KDJ 三指标同向"优先，再按固定池顺序兜底（确定性，同趋势腿"排序不是打分"原则——信号决定谁合格，排序只排合格者优先级）。

### 卖出（均值回归核心：回归即了结，不贪趋势）

**不照搬 resonance 的顶部共振卖出**，改用独立通道（OR 逻辑，先到先卖）：

1. **回归了结**：`close` 回升到布林中轨（=MA20）上方 → 卖。均值回归的目标就是中轨，这是主要了结点；
2. **超买了结**：`RSI(14) >= 70` → 卖。防止价格冲过头不回头；
3. **时间止损**：持有 ≥ N 天（候选 10 天）仍未触发回归/超买了结 → 离场。均值回归"错得快砍得快"，与趋势腿"让利润奔跑"哲学相反；
4. **ATR 止损**：触发即无条件卖（风控通道，不受最低持有限制）。

**回归了结的边界考量（2026-09-17 记录）**：
- 价格回归中轨后可能继续涨到上轨，这是"回归→趋势"的边界问题——贪中轨→上轨这段，本质是把均值回归滑向趋势跟随，而这 3 只有锚品种恰恰是趋势跟随历史翻车的品种（V14 红利、V2.x 国债）。
- **当前决策**：守住"回归中轨即卖"。有锚品种上中轨→上轨的期望值低，贪它往往是用确定的回吐风险去博低胜率的小利润。
- **已验证（训练期路径诊断）**：触下轨收回 124 次，62.9% 回到中轨。回到中轨后 34.6% 继续涨到上轨（+3.50%）、16.7% 跌回下轨（-1.39%）、48.7% 中轨附近震荡（+2.51%）。"中轨即卖"期望 +2.13% vs "继续持有" +2.20%，差异 0.07pp（噪声级），但继续持有要多担 16.7% 的 3.5pp 回吐 + 持仓拉长到 20 天。**结论：了结点保持中轨即卖，不上移；分级了结不启用。**

### 止损

- ATR(14) 跟踪止损，倍数候选 **2.0x**（均值回归持有期短、波动容忍低，比趋势腿 2.5x 更紧；resonance 用 2.5x，本腿收紧，待拍板）
- 品种级参数沿用 V2.8 验证结论：黄金 `stop_floor=0.03, trailing_atr_mult=2.0`；其余 `stop_floor=0.05 / stop_cap=0.15`
- 最高价用**收盘价**（AGENTS.md 铁律）

### 接飞刀防护（训练期 A/B 结论：去掉）

均值回归最怕接飞刀，但训练期（2017-2021）A/B 证明**事前防护是冗余或误杀，已去掉**：

- `close < MA60 且 MA20 斜率向下`：**误杀**——挡掉 71% 的 BOLL 事件（226 次里 160 次），且被挡掉的多数是盈利单（去掉后胜率 61%→78.6%）。有锚品种价格在 MA60 下方震荡是常态，不是趋势下跌。
- `连续 N 日创新低`：**冗余**——与买入共振的"当日反弹"要求互斥，共振本身已排除趋势下跌。
- 去掉后：训练期 +16.94%（vs 保留 -1.63%），56 笔，5 年全正（含 2018 熊市 +3.05%），最差单笔 -6.23%。
- **接飞刀风险由 ATR 止损（2.0x）+ 时间止损（10 天）兜底**，数据证明兜得住。
- 引擎 `knife_mode` 保留 `none/ma60_slope/ma60_slope_weak/new_low_10` 选项（默认 `none`），供验证期前重新审视；实验脚本 `research/meanrev_knife_ab.py`。

### 持仓与资金

- `max_hold = 2`，等分：每只新买入目标市值 = 总资产 × `base_ratio` / `max_hold`（A/B 结论：3 的第 3 槽从未用到，降到 2 消除仓位浪费，收益 +11pp、交易不变）
- `base_ratio` 候选 0.95（同趋势腿），留 5% 现金兜底
- 买入用 `order_target_value`
- **候选不足时留现金，不凑数**（同趋势腿原则）

### 防 whipsaw

- 同 ETF 买卖冷却 5 天
- 最低持有期 5 天（仅信号卖出；ATR 止损、时间止损不受限）

### 明确不做

- 不做市场状态择时切换（V9 教训）
- 不做"超卖加仓摊低成本"（接飞刀的放大器，坚决不做）
- 不做综合评分、不做横截面轮动、不做 ADX/量能参与交易

## 8. 定案结论（2026-09-17 确认）

| 项 | 定案 |
|---|---|
| 品种池 | 黄金 518880 + 红利 510880 + 豆粕 159985（先跑通）；国债 511010 待扩数据根后纳入；不加油气 |
| 买入共振 | BOLL 超卖收回（必选）+ RSI/KDJ 至少一个低位拐头 + 第三指标反向否决 |
| 卖出了结 | 回归布林中轨（=MA20）即卖 + 超买 RSI≥70 兜底（先到先卖）；先不考虑上轨 |
| 时间止损 | 10 天（安全阀，不扫描优化） |
| 止损倍数 | 2.0x ATR（黄金 0.03/2.0 已 V2.8 验证，其余 0.05/2.0） |
| 接飞刀防护 | 去掉（A/B 证伪：误杀 71% 或冗余），靠 ATR 止损 + 时间止损兜底 |
| 持仓 | max_hold=2，等分每笔 47.5%（A/B：3→2 收益 +11pp、交易不变、回撤 14.93% 仍在 15% 门槛内） |

**训练期实验结论（2026-09-17，采纳 vs 证伪）**：

采纳：
- **去掉接飞刀防护**：`ma60_slope` 误杀 71% BOLL 事件、`new_low_10` 冗余，靠 ATR + 时间止损兜底；
- **max_hold 3→2**：第 3 槽从未用到（实际最多持 2），等分 3 浪费仓位；降到 2 收益 +11pp、交易不变。

证伪（保留实验开关，默认关闭/回退）：
- **min_hold 缩短**：5 天最优（16.94% vs 1 天 14.91%），缩短会过早了结快速反弹；
- **回归后路径诊断**：了结点保持"中轨即卖"不上移（继续持有 +2.20% vs +2.13%，噪声级，却多担 16.7% 的 3.5pp 回吐）；
- **分级了结**：不启用（同上）；
- **去掉 BOLL 必选 / 深度 RSI 门槛**：BOLL 是价格位置的质量门槛，去掉后只剩动能维度，收益 16.94%→4.97%（深度门槛也救不回）；
- **DMI/ADX 下跌趋势退出**（借鉴 resonance）：把"回归前洗盘"误判为趋势下跌，砍在低点错过回归，16.94%→13.22%，负优化。

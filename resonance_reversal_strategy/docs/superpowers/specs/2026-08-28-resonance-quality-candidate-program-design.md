# 共振反转交易质量候选实验设计

## 1. 目标

在不读取 2022 年及以后数据、不删除 ATR、不改变 ETF 池和正式共振定义的前提下，
用可归因的独立实验改善 `resonance_reversal` 在 2019--2021 训练期的交易质量、收益、
最大回撤和资金利用率。

本设计只授权四个独立里程碑：

1. 建立可复现的候选绩效评估器；
2. 增加不影响订单的 ATR 退出影子观察；
3. 验证“硬 BOLL + 相对振荡器”的相对买入空槽补位；
4. 验证基于 T-1 收盘的 BOLL 买入逻辑失效退出。

四个里程碑不得直接合并实施。只有独立候选满足本设计的晋级门槛后，才能另行提出组合
候选规格并再次取得用户确认。

## 4. 实验程序与依赖关系

```text
基线 .4
  ├─ 里程碑 A：候选绩效评估器（只读，不下单）
  ├─ 里程碑 B：ATR 退出影子观察（订单必须与 .4 完全一致）
  ├─ 里程碑 C：相对买入空槽补位（唯一允许增加买单的候选）
  └─ 里程碑 D：BOLL 逻辑失效退出（唯一允许增加卖单的候选）

C、D 分别通过 → 另写组合候选规格 → 用户再次确认 → 才能组合
B 只提供 ATR 诊断 → 任何 ATR 删除/参数变化都必须另写规格
```

## 5. 里程碑 A：候选绩效评估器

### 5.1 职责

评估器只读取用户显式提供的 JoinQuant 日志和已校验 manifest，不读取行情、不调用交易
API、不搜索参数。它必须输出：

- 日历和输入数据质量；
- 每日净值、总收益、年度收益和最大回撤；
- 完整交易数、胜负数、胜率、95% Wilson 下界；
- 交易收益中位数、毛利润、毛亏损、Profit Factor；
- 前 10% 完整交易占毛利润比例；
- 按退出原因、入场来源、年份的分组结果；
- 普通摩擦和双倍摩擦候选的独立结果；
- 与最终硬门槛逐项对应的布尔值。

成交闭环必须按现金流处理：

```text
entry_cost = entry_price * entry_amount + entry_commission
exit_proceeds = exit_price * exit_amount - exit_commission
pnl = exit_proceeds - entry_cost
trade_return = pnl / entry_cost
```

买卖数量不同不自动判错；必须保留数量比并单独报告。重复开仓、无开仓卖出、无法确定成交
方向、非有限价格/手续费、非正数量必须 fail closed。

### 5.2 最终硬门槛

组合候选只有同时满足以下条件才允许请求进入验证期：

| 指标 | 硬门槛 |
|---|---:|
| 总收益 | `> 129.25%` |
| 完整交易胜率 | `> 55.8%` |
| 胜率目标 | 报告是否 `>= 60%`，但不能替代其他硬门槛 |
| 95% Wilson 胜率下界 | `> 50%` |
| 最大回撤 | `< 6.28%` |
| 完整交易数量 | `>= 80` |
| 交易收益中位数 | `> 0` |
| 前 10% 完整交易占毛利润 | `<= 50%` |
| 双倍摩擦总收益 | `> 64.10%` |

夏普、索提诺、平台盈亏比和本地 Profit Factor 作为诊断项，不增加新的硬门槛。

## 6. 里程碑 B：ATR 退出影子观察

### 6.1 范围契约

| 字段 | 契约 |
|---|---|
| 目标对象 | 已经完全成交并清仓的 `ATR_EXIT` 交易 |
| 目标阶段 | 卖单完成后注册观察；后续交易日收盘记录 H1/H3/H5 |
| 允许改变 | 新增独立影子状态、日志、只读分析器和 build 标识 |
| 必须保持不变 | ATR 触发、卖单提交、挂起重试、退出优先级、正式/相对观察、全部买卖订单和组合净值 |
| 不得传播到 | 买入资格、卖出资格、仓位、ATR 参数、冷却期、同日再买规则、正式 observation namespace |

### 6.2 注册合同

- 只在 `reason is ATR_EXIT`、卖出结果为 `FILLED` 且实际剩余数量为 0 时注册；
- ATR 仅触发但暂停、未知、未成交或部分成交时不注册；挂起卖单以后完全成交时注册一次；
- 参考价格使用该次 09:35 卖出决策可见的执行报价，不声称是券商最终成交均价；
- 记录原买入日、参考价格、入场价、冻结 entry ATR、最高收盘锚、止损价和卖出日；
- 使用独立 `ATR_SHADOW:` ID、独立 `g.atr_shadow_events`、独立注册/结果日志；
- 不得写入 `g.observation_events`，避免污染正式/相对观察分析；
- 普通影子记录异常只能生成诊断，不能回滚或阻止已经完成的 ATR 卖出；未来数据错误仍原样抛出；
- 收盘结果使用卖出日之后精确第 1、3、5 个交易日，训练期末采用与现有 manifest 相同的右截尾规则。

### 6.3 真值表

| ATR 场景 | 原卖单 | 注册影子 | 后续交易 |
|---|---:|---:|---|
| 未触发 | 不变 | 否 | 不变 |
| 触发且完全成交 | 不变 | 是，一次 | 不变 |
| 触发且部分/未成交 | 不变 | 否 | 原挂起重试不变 |
| 挂起 ATR 后重试完全成交 | 不变 | 是，一次 | 不变 |
| `SIGNAL_EXIT` 或以后可能出现的其他退出 | 不变 | 否 | 不变 |
| 影子注册普通异常 | 已完成卖单不得受影响 | 否，记录错误 | 不变 |

### 6.4 结论边界

影子报告只回答“止损后价格继续下跌还是反弹”。即使 H5 命中率和中位数为正，也只允许
提出新的 ATR 调整规格；不得自动删除 ATR、修改 2.5 倍数或改动 5%--15% 边界。

## 7. 里程碑 C：相对买入空槽补位

### 7.1 范围契约

| 字段 | 契约 |
|---|---|
| 目标对象 | `branch == HARD_BOLL_SOFT_OSC` 且 `direction == BUY_TURN` 的相对观察 |
| 目标阶段 | 正式买入队列全部处理之后，使用同一冻结的剩余槽位计数补位 |
| 允许改变 | 仅候选 build 的新增买入机会、相对买入日志和处理 ID |
| 必须保持不变 | 正式买入优先级、正式买入排序、正式卖出、ATR、现有相对观察注册、所有现有反重复/暂停/未知/未成交语义 |
| 不得传播到 | `SOFT_ALL_THREE`、任何 `SELL_TURN`、已持有加仓、同日卖出回购、满仓替换、相对指标阈值搜索 |

### 7.2 候选合同

相对交易候选必须同时满足：

1. 快照有效；
2. `build_relative_resonance_observation` 已形成合法观察；
3. `direction is BUY_TURN`；
4. `branch == HARD_BOLL_SOFT_OSC`；
5. 至少一个支持事件发生在 T-1；
6. 对应的正式完整买入共振不存在；
7. 入场 ATR 有限且为正。

运行时不得读取 H1/H3/H5 结果或任何聚合命中率。训练报告只是设计证据，不是交易输入。

相对候选排序固定为：

```text
支持指标数量降序 → ETF 代码升序
```

不得增加权重、分数或相邻阈值搜索。

### 7.3 正式优先和槽位语义

- 先完整执行现有正式买入队列；
- 正式候选的 `UNKNOWN`、`NOT_FILLED` 等原本会消耗意向槽位的结果继续消耗，不得让相对
  候选因重新读取实际持仓而“追单”；
- 正式候选只有 `PAUSED` 路径允许继续后备补位的现有语义保持不变；
- 相对候选只使用同一个 `remaining_slots` 变量；
- 相对候选的暂停允许尝试下一相对候选；未知、未成交或有效下单尝试消耗一个槽位；
- 已持有、`sold_today`、`daily_attempted_buys`、已处理 ID 和满仓检查与正式候选一致；
- 使用当前 `calc_buy_target_value` 和 `submit_buy`，不新增仓位折扣。

### 7.4 真值表

| 观察方向/分支 | 有正式空槽 | 是否进入相对交易队列 | 正式流程 |
|---|---:|---:|---|
| BUY + HARD_BOLL_SOFT_OSC | 是 | 是，正式队列之后 | 不变 |
| BUY + HARD_BOLL_SOFT_OSC | 否 | 否，只记录满仓原因 | 不变 |
| BUY + SOFT_ALL_THREE | 任意 | 否，继续观察 | 不变 |
| SELL + 任意分支 | 任意 | 否，继续观察 | 不变 |
| 正式完整买入共振 | 任意 | 相对构造本身抑制 | 正式候选不变 |
| 相对准备普通异常 | 任意 | 空队列 | 正式流程继续 |
| 相对准备未来数据错误 | 任意 | 不下相对单 | 已排前的 pending/ATR 风险退出不变；在任何正式信号卖单或买单前原样抛出 |

## 8. 里程碑 D：BOLL 买入逻辑失效退出

### 8.1 范围契约

| 字段 | 契约 |
|---|---|
| 目标对象 | 有可验证入场 BOLL 低点的策略持仓 |
| 目标阶段 | ATR 阶段之后、正式信号卖出之前，用 T-1 收盘判断，T 日 09:35 执行 |
| 允许改变 | 候选 build 中满足严格失效条件的卖出、持仓状态字段、退出日志和优先级枚举 |
| 必须保持不变 | ATR 先执行、正式卖出定义、卖单重试、正式买入、相对观察、仓位、ETF 池和全部指标参数 |
| 不得传播到 | 当前价/盘中低点参与失效判断、等于边界时卖出、无法证明入场低点的老状态、相对卖出 |

### 8.2 失效定义

买入成交时，从该次合法买入决策对应的正式 BOLL 买入事件保存
`entry_boll_reference_extreme`。以后仅当：

```text
T-1 close < entry_boll_reference_extreme
```

才形成 `BOLL_THESIS_EXIT`。严格小于才失效，等于边界不卖。当前 T 日 09:35 报价只用于
下单和成交，不得反向参与资格判断。

字段缺失、非有限、非正或快照无效时，本退出不执行；不得用当前 BOLL、ATR 价位或其他
指标猜测历史入场低点。ATR 和正式信号退出仍照常运行。

### 8.3 退出优先级

```text
ATR_EXIT (3) > BOLL_THESIS_EXIT (2) > SIGNAL_EXIT (1)
```

该优先级只控制同一持仓的挂起退出升级，不控制是否运行观察、买入或清理。

| 场景 | ATR | BOLL 失效 | 正式卖出 | 结果 |
|---|---:|---:|---:|---|
| ATR 已当日卖出 | 是 | 任意 | 任意 | ATR 一单；`sold_today` 阻止后续和回购 |
| ATR 未触发且 T-1 收盘严格低于入场低点 | 否 | 是 | 任意 | BOLL 失效一单 |
| T-1 收盘等于入场低点 | 否 | 否 | 按原规则 | 原正式流程 |
| 入场低点缺失/非法 | 否 | 不可判定 | 按原规则 | 原正式流程 |
| 挂起正式卖出后出现 BOLL 失效 | 否 | 是 | 已挂起 | 原因升级为 BOLL 失效，不重复下单 |
| 挂起 BOLL 失效后出现正式卖出 | 否 | 已挂起 | 是 | 不降级，不重复下单 |
| 挂起 BOLL 失效后出现 ATR | 是 | 已挂起 | 任意 | 原因升级为 ATR，不重复下单 |

## 9. 独立候选晋级门槛

### 9.1 相对买入候选

相对买入候选相对 `.4` 必须同时满足：

- 总收益严格提高；
- 最大回撤不高于 19.0577%；
- 完整交易数不少于 68；
- 胜率高于 55.8%；
- 交易收益中位数大于 0；
- 前 10% 完整交易占毛利润不超过 50%；
- 2021 年收益严格高于 -12.9805%；
- 日志证明没有相对卖出、`SOFT_ALL_THREE` 买入或正式队列优先级变化。

### 9.2 BOLL 失效退出候选

BOLL 失效候选相对 `.4` 必须同时满足：

- 总收益不低于 19.282%；
- 最大回撤严格低于 19.0577%；
- 胜率不低于 57.3529%；
- 交易收益中位数大于 0；
- 前 10% 完整交易占毛利润不超过 50%；
- 2021 年收益严格高于 -12.9805%；
- ATR 仍存在且参数、触发顺序和 5%--15% 边界不变；
- 正式信号退出定义不变。

独立晋级不代表达到最终对照目标，只代表可以申请组合实验。组合实验必须另行满足第 5.2
节的全部最终硬门槛。

## 10. 平台回放协议

每个候选只允许一次冻结规则的 2019--2021 主训练回放；不得根据结果搜索相邻阈值、
分支、窗口、ETF 或排序权重。

每个交易候选还需要一次相同规则、双倍滑点和双倍佣金的摩擦回放。双倍摩擦只改变平台
成交成本，不改变信号、排序、持仓或退出规则。

每次回放必须记录：

- 假设；
- 基线 commit 和候选 commit；
- build 与所有指纹；
- 规则差异；
- 训练结果；
- 门槛逐项结果；
- 解释；
- 是否晋级；
- 失败实验也必须保留，不得静默删除。

JoinQuant 是绩效权威。本地单元测试只证明代码合同，不证明收益。

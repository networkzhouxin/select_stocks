# 非极值相对拐点观察路径设计规格

- 设计日期：2026-08-27
- 设计状态：用户已批准聊天版设计，等待书面规格复核
- 基线提交：`5b8967524b0ef6b3ab74b1ae068c8a8311f332c2`
- 基线策略版本：`resonance-v0.1.0`
- 基线部署标识：`20260827.3`

- 目标平台：聚宽 JoinQuant

## 1. 背景与结构假设

当前策略把固定极值区域当作方向事件的价格位置门槛：RSI 使用 30/70，KDJ 使用 20/80 与 J=0/100，BOLL 要求触及上下轨。该设计能过滤普通波动，但会遗漏未进入固定极值区便转向的行情。

2019—2021 聚宽训练日志同时显示，问题不能通过直接删除阈值处理：

- 三年共有 286 个完整买入共振和 70 次实际买入，信号并不枯竭；
- 2021 年共有 21 次 ATR 退出，失败入场多于前两年；
- 完整买入共振中 281/286 包含 KDJ，RSI 的独立补充作用有限；
- 现有 39 次普通信号退出中 36 次盈利，没有证据支持立即放宽正式卖出。

本轮只检验一个结构假设：**保留现有极值交易路径，同时建立完全隔离的非极值相对拐点观察路径，判断它能否补充有质量的增量机会，而不增加 2021 式失败信号。**

相对路径在本轮永远不能下单。训练结果通过预注册门槛后，也只能获得创建一个后续交易候选的资格。

## 3. 术语与数据索引

对任一候选事件日 `i`，只使用三根已完成日线：

- `a = i-2`；
- `b = i-1`；
- `c = i`。

在 T 日 09:35，最新允许的 `c` 是 T-1。为了同时检测 T-2 与 T-1 事件，计算函数至少接收截止 T-1 的最后四根完整日线。

事件方向仍使用现有 `TurnDirection.BUY_TURN`、`SELL_TURN`、`NEUTRAL`。相对事件必须明确标记 `event_mode="RELATIVE"`，不得用裸布尔值同时表示方向、有效性和观察资格。

## 4. 相对指标事件

### 4.1 RSI14 相对事件

不使用 30/70，也不要求穿越任何水平线。

```text
RELATIVE_RSI_BUY:
    RSI[a] >= RSI[b]
    and RSI[c] > RSI[b]

RELATIVE_RSI_SELL:
    RSI[a] <= RSI[b]
    and RSI[c] < RSI[b]
```

这表示 RSI 在 `b` 形成局部低点或高点后，于 `c` 出现第一步反向变化。任一输入为 NaN 时返回 `NEUTRAL`。

### 4.2 KDJ 相对事件

定义 `KD_DIFF = K - D`。不使用 K/D=20/80、J=0/100，也不要求正式交叉。

```text
RELATIVE_KDJ_BUY:
    J[a] >= J[b]
    and KD_DIFF[a] >= KD_DIFF[b]
    and J[c] > J[b]
    and KD_DIFF[c] > KD_DIFF[b]

RELATIVE_KDJ_SELL:
    J[a] <= J[b]
    and KD_DIFF[a] <= KD_DIFF[b]
    and J[c] < J[b]
    and KD_DIFF[c] < KD_DIFF[b]
```

这要求 J 与 K-D 差值在同一日共同反向，避免把单个分量的普通波动当作拐点。任一输入为 NaN 时返回 `NEUTRAL`。

### 4.3 BOLL 相对事件

使用现有 BOLL 中轨、上下轨，不增加新周期或倍数。定义：

```text
PERCENT_B[x] = (close[x] - lower[x]) / (upper[x] - lower[x])
```

当轨道宽度非正、非有限或任一必要输入为 NaN 时返回 `NEUTRAL`。

```text
RELATIVE_BOLL_BUY:
    close[b] < mid[b]
    and PERCENT_B[a] >= PERCENT_B[b]
    and PERCENT_B[c] > PERCENT_B[b]
    and close[c] > close[b]
    and low[c] >= low[b]

RELATIVE_BOLL_SELL:
    close[b] > mid[b]
    and PERCENT_B[a] <= PERCENT_B[b]
    and PERCENT_B[c] < PERCENT_B[b]
    and close[c] < close[b]
    and high[c] <= high[b]
```

中轨只提供随价格变化的相对位置，不是待搜索的固定数值阈值。BOLL 相对事件不要求触及上下轨。

### 4.4 相对事件生命周期

- 事件在事件日与下一交易日有效，窗口与正式路径一致；
- 两个支持事件至少一个必须发生在最新信号日 T-1；
- 同一相对指标出现更新的反向事件时，旧事件立即失效；
- BOLL 相对买入事件以后若出现比事件参考低点更低的新低，原事件失效；
- BOLL 相对卖出事件以后若出现比事件参考高点更高的新高，原事件失效；
- 硬事件与相对事件保存在不同事件簿中，生命周期互不改写；
- 组合阶段若发现任一仍有效的硬事件或相对事件与候选方向相反，观察候选被否决。

## 5. 观察型共振

只记录没有形成现有 `COMPLETE_RESONANCE` 的增量候选。相同代码、方向和支持事件已经形成正式共振时，不得再登记为相对候选。

### 5.1 分支 A：`HARD_BOLL_SOFT_OSC`

必须同时满足：

1. 现有正式 BOLL 事件支持目标方向；
2. 相对 RSI 或相对 KDJ 至少一个支持目标方向；
3. 另一个振荡指标的有效硬事件或相对事件均不得反向；
4. 支持事件均在两交易日窗口内；
5. 至少一个支持事件发生在 T-1；
6. 当前正式路径没有形成完整共振。

该分支观察“价格已到达 BOLL 极端区域，但振荡指标没有进入固定极值便开始反转”的情况。

### 5.2 分支 B：`SOFT_ALL_THREE`

必须同时满足：

1. 相对 BOLL、相对 RSI、相对 KDJ 三项全部支持同一方向；
2. 三项均在两交易日窗口内；
3. 至少一项发生在 T-1；
4. 任一有效硬事件或相对事件均不得反向；
5. 当前正式路径没有形成完整共振。

该分支在 BOLL 未触轨时要求三个维度全部确认，不允许仅凭两个相关振荡指标产生候选。

### 5.3 真值摘要

| 正式 BOLL | 相对 BOLL | 相对 RSI | 相对 KDJ | 反向事件 | 结果 |
|---|---|---|---|---|---|
| 同向 | 任意 | 同向 | 中性/同向 | 无 | 分支 A 观察 |
| 同向 | 任意 | 中性 | 同向 | 无 | 分支 A 观察 |
| 中性 | 同向 | 同向 | 同向 | 无 | 分支 B 观察 |
| 中性 | 同向 | 同向 | 中性 | 无 | 不观察 |
| 中性 | 中性 | 同向 | 同向 | 无 | 不观察 |
| 任意 | 任意 | 任意 | 任意 | 有 | 冲突，不观察 |
| 正式路径已完整共振 | 任意 | 任意 | 任意 | 无 | 仅保留正式观察，不重复登记 |

## 6. 观察对象与标识

相对候选只包含观察所需字段：

```text
relative_observation_id
observation_kind = "RELATIVE_RESONANCE"
branch = "HARD_BOLL_SOFT_OSC" | "SOFT_ALL_THREE"
code
direction
signal_date
supporters
supporter_event_dates
hard_or_relative_source_by_indicator
expires_date
event_close
```

标识由观察类型、分支、方向、ETF 代码、支持指标、事件模式和事件日期生成稳定哈希，并使用 `RELATIVE:` 命名空间，禁止与正式 `resonance_id` 碰撞。

初始化日志增加 `relative_observation_fingerprint`。指纹合同必须包括本规格中的三类事件谓词、两个分支、两日窗口和反向否决语义，但不得改变现有参数指纹和正式事件逻辑指纹。

## 7. 数据流与控制流隔离

```text
截止 T-1 的指标帧
 ├─ 正式事件簿 → 正式共振 → ATR/卖出/买入/订单（完全不变）
 └─ 相对事件簿 → 相对观察共振 → 观察注册 → 1/3/5 日结果日志
```

`do_trading` 中相对观察只能作为一个无返回值副作用阶段执行。它不得改变或包围原有 ATR、正式卖出和正式买入阶段，也不得用相对观察是否存在作为提前返回条件。

调用方契约：

| 调用场景 | 相对观察是否运行 | 核心交易是否运行 | 必须保持的行为 |
|---|---:|---:|---|
| 相对候选存在 | 是 | 是 | 原订单路径不变 |
| 相对候选不存在 | 是 | 是 | 不增加提前返回 |
| 普通观察注册失败 | 尝试并记录失败 | 是 | ATR、卖出、买入继续 |
| `FutureDataError` | 立即重新抛出 | 否 | 回测明确失败，不吞未来数据错误 |
| 正式信号快照无效 | 不生成相对候选 | 原有风险路径仍运行 | 不扩大无效数据影响 |

不新增布尔或模式参数。相对观察始终是观察职责；是否将来进入交易只能通过新的策略候选和用户重新批准，不能用隐藏开关完成。

## 8. 观察结果

相对候选复用现有收盘后 1/3/5 交易日观察机制，但使用命名空间标识。候选在 T 日 09:35 注册时保存 T-1 收盘价，未来表现只能在对应交易日 15:30 已收盘后写入。

方向调整收益定义：

```text
BUY_TURN:  direction_adjusted_return = raw_return
SELL_TURN: direction_adjusted_return = -raw_return
```

结果日志必须能通过观察 ID 关联回分支、方向、支持指标和事件日期。结果不得写回快照、正式事件簿、排序、仓位或风险状态。

## 9. 只读训练分析工具

新增工具只读取用户导出的聚宽日志，不读取本地行情目录，不重新计算市场指标，不产生订单。训练报告必须拒绝包含 2022 年及以后观察候选或结果的输入，避免验证数据混入规则选择。

报告分别统计正式共振、相对候选总集和两个分支：

- 候选总数、方向、年份和 ETF 分布；
- 与正式共振的重合数，预期必须为 0；
- 1/3/5 日方向调整收益的均值、中位数、命中率、下四分位数；
- 2021 年单独表现；
- 单一 ETF 对全部正向收益的最大贡献；
- 缺失、重复、过期、跨 build 或指纹不一致记录。

工具不得提供阈值搜索、窗口搜索、ETF 删除建议或自动晋级结论。

## 10. 预注册继续门槛

以下门槛只决定是否值得创建一个后续交易候选，不代表策略通过训练或可以进入验证期：

| 指标 | 门槛 |
|---|---:|
| 增量候选总数 | 至少 30 个 |
| 年度覆盖 | 2019、2020、2021 每年至少 5 个 |
| 5 日方向调整收益中位数 | 大于 0 |
| 5 日方向命中率 | 大于 50% |
| 2021 年 5 日方向调整收益中位数 | 不低于 0 |
| 5 日方向调整收益下四分位数 | 不差于同期正式共振的 5 日方向调整收益下四分位数 |
| 单一 ETF 正向收益贡献 | 单只 ETF 的正向 5 日方向调整收益之和，不超过全体正向 5 日方向调整收益之和的 50% |
| 正式订单路径 | 与 `20260827.3` 基线逐笔一致 |

正式订单路径基线为 2019—2021 日志中的 138 个 `FILLED` 状态迁移。应核对日期、方向、代码、前后数量，并核对期末资产 23,856.40 元；若聚宽历史数据修订造成漂移，必须先定位差异，不能解释相对观察结果。

任一门槛失败时：

- 记录为拒绝的结构假设；
- 不搜索 RSI/KDJ/BOLL 邻近阈值；
- 不把两日窗口改成一日或三日；
- 不删除表现差的年份或 ETF；
- 不创建第二套相对定义补救本轮结果。

全部通过时，只能提出一份“相对路径进入交易的候选规格”，并再次等待用户批准。现有正式训练硬门槛和验证顺序仍然适用。
